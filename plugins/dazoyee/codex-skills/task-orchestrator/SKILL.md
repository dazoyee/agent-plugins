# task-orchestrator（Codex 用）

手順の本体は Claude Code 用のスキル `../../skills/task-orchestrator/SKILL.md`（この SKILL.md のディレクトリ基準）にある。
最初にそのファイルを読み、判断基準・分解・委譲プロンプトの書き方・総括レポートの構成にそのまま従う。
ただし Claude Code 専用のツールと仕組みは、次の対応表に従って読み替える。

## 読み替え表

| 本体の記述 | Codex での扱い |
|---|---|
| Agent ツールでサブエージェントを起動 | `spawn_agent` で作業単位ごとに1つ起動する。独立な単位は待たずに続けて起動する |
| 結果を受け取る | `wait_agent` で起動したエージェントの完了を待ち、結果を集める。終わったら `close_agent` で閉じる |
| 起動済みワーカーへの追加指示 | `send_input` |
| `TaskCreate` / タスクの状態更新 | `update_plan` で作業単位ごとの計画を作り、状態を更新する |
| `isolation: "worktree"` | 使えない。同じファイルを触る作業は並列にせず、1つのワーカーにまとめる |
| Workflow ツール | 使えない。数十件規模の作業はバッチに分けて逐次オーケストレーションする |

サブエージェントの機能（`spawn_agent` など）が使えない環境では、作業単位を順番に自分で処理し、
同じ総括レポートの構成で返す。
